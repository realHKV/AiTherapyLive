In either case, keep secret values out of Git, Terraform variables/state, and chat; check Google OAuth and Razorpay test-mode credentials before starting the service.
3. For the advanced-features/App Runner path only: apply `create_service=false`, mirror the reviewed Step 14 image by digest, run the one-off Flyway migrator on Neon, then apply `create_service=true` with the exact ECR digest. Record the AWS service URL, image digest, migration version, and deployment operation IDs. A failed migration stops before service creation.
