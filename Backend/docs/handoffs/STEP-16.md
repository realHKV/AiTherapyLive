## Free-plan architecture under review

- Keep the React site on Netlify. It supplies the frontend hostname, but the Spring backend still needs a reachable HTTPS API hostname for browser requests, Google OAuth, and Razorpay. A separate DNS account or purchased domain may be avoidable: a CloudFront distribution provides an AWS HTTPS hostname; its origin can be a single always-on EC2 instance in Sydney. This is a candidate to validate, not a deployed service. [CloudFront domain](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/DownloadDistValuesGeneral.html), [supported services](https://docs.aws.amazon.com/accounts/latest/reference/supported-services-sign-up-new.html).
- Candidate: one small EC2 instance with an IAM instance profile for Bedrock, ECR, and secret retrieval, an Elastic IP for a stable origin address, and the instance's public DNS name as CloudFront's custom origin. No ALB, NAT gateway, RDS, ElastiCache, or frontend S3 hosting. Restrict origin ingress to CloudFront's managed origin-facing prefix list **and** require a distribution-specific secret header at the instance proxy. Resolve secure CloudFront-to-origin transport before deployment; a public HTTP origin would expose authenticated requests between CloudFront and EC2. Disable CloudFront API caching, forward Authorization/cookies/query strings/Origin, preserve the external host and HTTPS scheme for OAuth, and test signed webhook forwarding. [Managed prefix list](https://docs.aws.amazon.com/vpc/latest/userguide/working-with-aws-managed-prefix-lists.html), [origin authentication](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/add-origin-custom-headers.html), [origin request policy](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/controlling-origin-requests.html).
- CloudFront's origin read timeout is configurable to 120 seconds and can forward chunked responses; this is suitable to *test* the 90-second SSE path, but does not prove it works until a real browser stream passes. Ordinary Netlify proxy rewrites have a 26-second timeout, so they are not the default API route. If Google's OAuth console rejects the assigned CloudFront hostname, validate a Netlify Edge Function proxy for the OAuth paths or use a free DNS subdomain; do not assume either works without a live callback. [CloudFront origin timeout](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/DownloadDistValuesOrigin.html), [custom-origin response behavior](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/RequestAndResponseBehaviorCustomOrigin.html), [Netlify rewrites](https://docs.netlify.com/manage/routing/redirects/rewrites-proxies/).
- A Sydney `t3a.small` quote was $0.0238/hour (~$17.37 at 730 hours), plus public IPv4 ~$3.65/month, EBS, CloudFront traffic, logs, and Bedrock. This exceeds the $15 gross-cost alert even before extras; it is a notification, not a cap. Compare a memory-safe smaller instance and monitor actual spend before claiming a monthly total. Set burstable CPU credit mode to `standard` to avoid unlimited-mode surplus charges. Warm EC2 avoids backend cold starts, but Neon compute sleep can still add first-query latency. [Public IPv4 pricing](https://aws.amazon.com/vpc/pricing/), [CPU credit modes](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/burstable-performance-instances-unlimited-mode.html).
